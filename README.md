# Muralidharan Lakshmanan — Professional Website

Static personal website for GitHub Pages.

## Files
- `index.html` — site content
- `styles.css` — responsive styling
- `script.js` — navigation and small visual effects
- `assets/headshot.jpg` — optimized professional portrait

## Publish on GitHub Pages
Upload all files and the `assets` folder to the root of the repository `muralidharanlakshmanan.github.io`.

The site should then be available at:
`https://muralidharanlakshmanan.github.io`

Custom domain setup can be added later after the GitHub Pages site is confirmed working.
